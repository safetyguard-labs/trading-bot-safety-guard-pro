# Privacy Policy

Last updated: November 2, 2026.

Trading Bot Safety Guard Pro is designed to inspect repository configuration for defensive security findings. During the development preview, the service does not sell personal information and does not request exchange API secrets.

When the hosted service launches, this policy will be expanded to identify the data processed, retention periods, subprocessors, deletion procedures, and contact method. Repository content will be accessed only with permissions granted through the GitHub App installation.

Questions may be sent to the contact address listed on the SafetyGuard Labs GitHub organization.
